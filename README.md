# 🔥 Consistency Lab

> A behavioral productivity system designed to build momentum, enforce accountability, and eliminate task procrastination through intelligent tracking and feedback loops.

Consistency Lab is not just a task manager — it is a structured consistency engine that tracks task age, momentum patterns, completion behavior, and priority escalation in real time.

---

## 🧠 Core Philosophy

Consistency Lab focuses on:

* Momentum over motivation
* Behavioral feedback over simple reminders
* Visibility of delay patterns
* Smart defaults that encourage action

# 🚀 Features

---

## 🏠 Multi-View Workspace

### Dashboard (`/`)

Central command hub displaying:

* Momentum metrics
* Consistency streak
* Urgent priorities
* System status alerts

### Tasks (`/tasks`)

Dedicated workspace for:

* Adding new goals
* Managing active tasks
* Filtering and searching

### Completed (`/completed`)

Historical archive showing:

* Completion duration
* Performance breakdown
* Filtered achievement history

* **Daily Momentum Tracking**
* **Lifetime Momentum Tracking**
* **Consistency Streak Counter (🔥)**

* Real-time momentum recalculation

## 🧩 Priority Focus System

* Custom “Minimum Forwarded” threshold
* Automatic detection of repeatedly delayed tasks
* High-contrast urgent UI state
* Dashboard pulses red when priority tasks exist
* Visual escalation for falling-behind goals

## 🔍 Advanced Filtering Logic

### Active Task Age Filter

Filter tasks by:

* Today
* Yesterday
* 2+ Days in Lab

### Completion Duration Filter

Filter completed tasks by:

* 0 days
* 1 day
* 2+ days to complete

### Real-Time Search

* Instant title-based filtering
* Works across all pages

### Category Filtering

* Coding
* DSA
* Health

Condition-based system messages displayed dynamically:

Examples:

Behavior-aware feedback without AI overengineering.

### Undo Delete

* 5-second styled toast
* Blue header
* Orange task highlight

### Quick Confirmation

* 2-second success toast on task creation

## 🔄 Smart Defaults

* **Auto-Forwarding:**
  Incomplete tasks automatically move to "Today" on each app launch
  Forwarded count increments automatically

* **Coding-First Default:**
  New tasks default to the "Coding" category for faster input
